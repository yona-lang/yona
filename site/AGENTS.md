## Yona documentation (keep current)

This directory is the **published** Yona 2.0 documentation. Learn, Guides,
Reference, and `/agents` pages are **handwritten**. Stdlib pages under
`src/content/docs/stdlib/` are generated by `pnpm sync` from `docs/api/`
(itself from `##` comments via `scripts/gendocs.py` at the repo root).

The legacy Yona 1.x site remains at
[yona-lang.github.io](https://yona-lang.github.io/) — do not overwrite that
repository.

When the language, CLI, prelude, or stdlib changes, update the matching
pages here **in the same change**. Verify examples with `yonac`:

- Comments are `#` / `/* */`, not `--`
- Prelude functions are only `identity`, `const`, `flip`, `compose`
- `foldl` / `map` / `filter` require `import … from Std\List`
- `with` is `with name = resource in body` (no `as`, no `daemon`)
- Sequences are flat arrays / radix-balanced tries, not red-black trees
- `Std\Stream` is `Yield a (() -> Stream a) | Nil`

Local preview: `python3 scripts/gendocs.py && cd site && pnpm dev`

## Development (Astro)

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and
`astro dev logs`.
